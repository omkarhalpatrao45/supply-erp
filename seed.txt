── HOW TO RESEED ──────────────────────────────────────────────────────────────

1. Drop and recreate the database:
   psql -U postgres -c "DROP DATABASE supply_erp;"
   psql -U postgres -c "CREATE DATABASE supply_erp;"

2. Apply the schema:
   psql -U postgres -d supply_erp -f backend/schema.sql

3. Run the seed script:
   cd backend
   npm run seed
